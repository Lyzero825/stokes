# ampere

Static desk: manuscript + instrument. The reading is the product. Token = flag — not wired to the math.

## Local

Open `index.html` in a browser (or any static host root = this folder).

## Launch fill-in

Edit the bootstrap `window.STOKES` object in `index.html` (or set it before `main.js` — config key kept for compatibility):

- `siteUrl` — origin with no trailing slash, e.g. `https://ampere.example`
- `xUrl` — full X profile URL (set: `https://x.com/Ampere_hood`)
- `ca` — mint address
- `caShort` — optional display trunc; empty = auto
- `gmgnUrl` — optional chart link for the CA slot

Leave unset fields empty until real. Empty ⇒ honest TBA chrome, no fake links.
