From the desk

For a few years now I have watched wallet pages sell the same costume. A balance. A PnL chart. A gallery of pictures the address once touched. The pitch never really changes. You open a tab, you watch numbers move, and you tell yourself you have read the wallet. Something about that shape always bothered me. The thing being measured was almost never the thing that actually closed.

A wallet is not a pile. It is a boundary. Value crosses it, loops around it through counterparties, and sometimes returns changed. Most tools flatten that loop into a score and ask you to trust the flattening. I started asking a different question. What would it mean to keep the circulation itself — the signed winding of a closed trade path — instead of inventing a story on top of it?

Stokes is the answer I kept arriving at.

On the name

George Gabriel Stokes spent the middle of the nineteenth century writing equations that refused to decorate themselves. The result that carries his name is simple enough to say out loud: the circulation of a field around a closed curve equals the flux of its curl through any surface that curve bounds. The boundary knows the interior. The loop knows the sheet. Nothing in the statement asks you to believe a narrative. It asks you to finish the integral.

That is the whole reason for the name. Not because a wallet is a fluid, and not because markets are Maxwellian, but because the honest object is already a closed path — and the honest measurement is the circulation around it. Stokes did not invent the flow. He named the equality that was always there.

The primitive

Most tokens are a story bolted onto a supply curve, and the bolt is where they break: the story can promise anything while the mechanism quietly does something else. Stokes has no bolt. The story — keep the running circulation of a closed wallet path — and the instrument — append each signed segment as it arrives — are not two things that happen to rhyme. They are the same object, one process written in two languages.

Concretely: take an address as a boundary. Reconstruct a closed path of counterparties and transfers over a fixed window. Each edge carries a signed contribution. The running total is Γ. The sign of Γ says which way the loop has been winding. The reading is the product. Nothing here forecasts. Nothing here asks you to trust a team’s character. An instrument does not ask for trust. It shows its work.

On the path

A path is not a history dump. It is a closed sequence: every outbound edge that leaves the boundary should, in the window you chose, find its return — or fail to, which is itself information. Stokes treats failure to close as a measurable defect in the loop, not as missing UI. Wash loops wind fast and cancel. One-way drains leave a scar in Γ that does not pretend to be symmetry.

The window is fixed at 256 steps in the illustrative desk, the same length Mark-style instruments use when they want a number you can recompute by hand. Longer windows are possible; they are not magic. They are more of the same integral.

01 / 08 · What this is

Stokes is a page that keeps a count. It reads public chain state anyone else can read, and it appends each new segment as it comes in. The curve on this page is not a mood. It is the geometry of a path that already closed — or failed to — before anyone looked.

Open the instrument to scrub regimes, seed paths, and watch Γ update from the same shoelace step the source overlay prints. Paste the step into a console. Get the same number. That reproducibility is not a marketing claim. It is the product wearing its insides on the outside.

On the constant

There is one constant in the whole procedure that matters for orientation: a full wind is a turn of 2π in the signed sense the instrument uses for display. It is what it is. Nobody on this desk picked it because it felt branded. The point of the constant is that nobody picked it.

If the answer someone wants is not derivable from the path and the public feeds Stokes reads, the answer they want is not part of the instrument. That sentence is the entire security model written without a security theater. Upgrade authority: none intended. Keys: not a feature of the reading. The winding was happening before the chart, and it will outlast it.

On the flag

If there is a token beside this page, treat it as a cultural handle — a community flag — not as a wire into Γ. Brand layer · not wired to the math. We would rather be explicit and unexciting here than let anyone fill the gap with assumptions. The float does not move the circulation. The page does not invent it. Observers keep the count.

What you are looking at

Each regime is a different lie markets tell about a loop. Independent drift keeps Γ near a living wind. Wash loops spin hard and cancel. Drains refuse to close. Whale ramps straighten the geometry until the wind looks polite and false. Stokes does not grade them with adjectives. It keeps the integral.

source / of / code

The heart of the reading is one step. Paste it into a console and get the same number the desk prints. Nothing below claims to be the full ingestion pipeline. It is the equality the rest of the page is built to protect. 

// Stokes — circulation step (shoelace segment)
// Γ_{n+1} = Γ_n + ½ (x_n y_{n+1} − x_{n+1} y_n)

function stepGamma(G, x0, y0, x1, y1) {
  return G + 0.5 * (x0 * y1 - x1 * y0);
}

function circulation(pts) {
  let G = 0;
  for (let i = 0; i < pts.length - 1; i++) {
    const a = pts[i], b = pts[i + 1];
    G = stepGamma(G, a.x, a.y, b.x, b.y);
  }
  return G;
}

const TWO_PI = Math.PI * 2;
// winds ≈ Γ / TWO_PI — nobody chose 2π; it is orientation

From the drafter

I want to be plain about what this is and what it is not, because the honest version is more interesting than the hyped one. Stokes is a small idea on purpose. It is not a company with a roadmap suite. It is a desk that keeps a circulation count for closed wallet paths, and a manuscript that refuses to bolt a costume onto that count.

What is here now is enough to see the thought run and to argue with it: the manuscript, the instrument, the step in source. I am not going to dress it up as audited, mainnet-hardened infrastructure, because it isn’t, and pretending otherwise would break the one promise the whole thing is about. If it is wrong, it should be easy to show that. If there is something here, it should be easy to build the next thing on top of it — deeper, in the open.

I am not going to tell you this is inevitable or that it wins. I genuinely don’t know. What I believe is that wallets are boundaries, that boundaries deserve integrals rather than costumes, and that trust has to rest on something you can recompute. Beyond that, the future of an idea is not the author’s to assign. We set it down with nothing hidden and nothing promised, and the people who keep looking decide whether the field is worth staying in.

That is the honest deal, and it is the only one on offer.
